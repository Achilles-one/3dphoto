# 3D Photo Lab 页面规格

## 当前流程

1. 空状态时，上传区域位于对齐预览舞台内部，支持点击和拖拽。
2. 上传或解析期间，舞台显示加载状态并阻止重复输入。
3. 解析完成后直接进入对齐预览并在后台尝试自动主体对齐；不显示独立预览导航，也不展示 Split Preview 页面。
4. JPG/PNG 可切换 SBS 与 Top-Bottom；MPO 的布局图标保留但禁用。
5. 自动对齐成功后水平、垂直滑块显示计算结果；失败时保持当前数值并给出非阻断提示。对齐预览始终提供水平、垂直、叠加强度和重置对齐，用户操作会取消尚未完成的自动任务。
6. 创建 Wiggle 后自动进入 Wiggle 预览并播放。
7. Wiggle 控件纵向排列，支持播放/暂停、Speed、交换左右眼、中间帧和调整对齐。
8. 删除按钮使相关任务失效、释放资源、清空源文件并恢复初始状态。
9. 下载弹框支持 GIF/MP4 取景与尺寸、MPO SBS PNG、编码能力提示、取消和失败恢复。

## 页面状态

| 状态 | 舞台 | 主要动作 |
|---|---|---|
| empty | 舞台内上传区域 | 上传或拖入文件 |
| loading | 上传/解析遮罩 | 等待或由任务失效恢复 |
| alignment | 对齐画布；自动任务运行时显示非阻断状态 | 调整、切换布局、创建 Wiggle、删除；任一用户动作优先于自动结果 |
| creating | 创建遮罩 | 等待或由任务失效恢复 |
| wiggle | Wiggle 画布和纵向控件 | 播放、调整、下载、删除 |
| exporting | 下载弹框进度 | 取消或等待完成 |
| error | 舞台内错误与重新上传入口 | 重试、删除或上传新文件 |

## 交互与无障碍

- 当前模式以文本显示，不提供预览导航 Tab。
- 自动对齐状态通过可感知的短文本表达，不遮挡画布、不禁用手动滑块；成功提示“已自动对齐，可继续微调”，低置信度、运行失败或超过 30 秒时提示“未能可靠识别主体，请手动调整”。自动任务无论以何种路径结束，都不能继续显示“正在识别主要主体”。
- Loading、错误和顶部消息通过可感知的状态语义表达，不只依赖颜色。
- 弹框管理焦点，Escape 和取消行为遵循 `UI.md`。
- `prefers-reduced-motion` 下不依赖持续旋转或快速动画表达状态。
