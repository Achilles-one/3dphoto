# Homepage 页面规格

## 状态

v1 已批准概念基线；当前代码仍以 3D Photo Lab 为主要可用页面，Homepage 作为后续页面规格保留。

## 目的

Homepage 是 Achilles Cat 的编辑型入口，用于表达个人数字影像档案、精选作品和进入 Lab 的路径，不承担照片处理逻辑。

## 页面结构

1. 全局头部：Achilles Cat、Works、Archive、MiuMiu、Lab、语言和 Settings。
2. 开场区域：品牌语气和当前项目入口。
3. Selected Works：精选影像和 3D Photography 入口。
4. Archive Preview：档案入口。
5. MiuMiu 区域：作为未来内容栏目。
6. 页脚：版本、隐私和反馈。

## 交互边界

- 页面结构和视觉层级以 `design/DESIGN_CONCEPTS.md` 为基线。
- 未实现的栏目保持明确的非交互占位，不伪造页面跳转。
- 视觉 token 统一引用 `design/DESIGN_SYSTEM.md`，不在本文件复制颜色和字体表。
