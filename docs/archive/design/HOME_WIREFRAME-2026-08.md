# Achilles Cat Homepage Wireframe

Version: v1.0

---

# 1. Page Purpose

## Identity

The homepage is the entrance of Achilles Cat.

Achilles Cat is not a SaaS product website.

It is a personal digital archive combining:

- Photography
- 3D imaging experiments
- Visual works
- MiuMiu archive
- Creative tools


The homepage should make visitors feel:

"This is a small digital world created by someone who cares about images."


---

# 2. Primary Goals

The homepage should:

1. Establish Achilles Cat identity
2. Showcase selected visual works
3. Guide users into different areas:

- Works
- Archive
- MiuMiu
- Lab


The homepage should NOT:

- Sell a product
- Explain features like SaaS landing pages
- Focus only on 3D Photo

# 4. Section Specifications


## 01. Global Navigation


Purpose:

Provide quiet access to the digital archive.


Navigation:

- Works
- Archive
- MiuMiu
- Lab
- About


Style:

- Minimal
- Editorial
- Lightweight

Desktop header must match the 3D Photo Lab header exactly:

- Left: `ACHILLES CAT`, thin vertical divider, `Works`, `Archive`, `MiuMiu`, `Lab`.
- Right: `EN / 中文`, `Settings`, and the small muted blue-green state dot.
- Use the same spacing, baseline, hairline rule, active route treatment, and
  responsive behavior as the Lab header.


Avoid:

- Large SaaS navigation
- Multiple CTA buttons


---

# 02. Hero / Opening Scene


Purpose:

Create emotional connection.

The first screen should introduce:

- Depth
- Photography
- Curiosity
- Exploration


Main message:

Looking at the world in depth.


Supporting idea:

Photography, stereoscopy and visual experiments.


Layout:

Two-part composition:

Left:

- Title
- Short description
- Entry link


Right:

- Large visual artwork


Main visual:

A representative 3D image.

The image is the focus.


Interaction:

- Subtle depth movement
- Slow parallax
- Gentle animation


Avoid:

- Marketing slogans
- Feature lists
- Product comparison


---

# 03. Selected Works


Purpose:

Show Achilles Cat as a visual archive.


Content categories:


## 3D Photography

Stereo images and depth experiments.


## Photography

Personal photography works.


## MiuMiu

Daily visual archive of a cat.


## Experiments

Other visual studies.


Layout:

Editorial grid.

Not:

Generic card collection.


Each item should include:

- Image
- Title
- Short description
- Year / metadata if available


Interaction:

Hover can reveal:

- additional information
- subtle motion
- preview effect


---

# 04. Archive Preview


Purpose:

Connect current works with personal interests.


Possible content:

- Cameras
- Stereo history
- Notes
- Field records


Feeling:

A personal archive.

Not:

A technical database.


---

# 05. MiuMiu Section


Purpose:

Introduce the emotional and personal side of Achilles Cat.


Position:

MiuMiu is not a pet product.

It is a visual diary.


Content:

- Photos
- Stories
- Daily observations
- Creative experiments


Style:

Personal.
Warm.
Quiet.


Avoid:

- Pet store feeling
- Generic cute animal design


---

# 06. Journal / Notes


Purpose:

Keep the website alive.


Content:

- Photography notes
- Development process
- Equipment notes
- Experiments
- Stories


Feeling:

Personal field notes.


---

# 5. Layout Principles


Use:

- Editorial composition
- Asymmetric layouts
- Large visual areas
- Negative space
- Clear hierarchy


Avoid:

- Dashboard layout
- Feature cards everywhere
- Excessive rounded containers
- SaaS landing page structure


---

# 6. Motion Principles


Motion should support:

- Depth
- Discovery
- Image appreciation


Recommended:

- Image parallax
- Hover depth effect
- Smooth transitions


Avoid:

- Decorative animation
- Heavy WebGL effects
- Particle backgrounds


---

# 7. Implementation Notes


The homepage should be built as a brand shell.

Future sections should be able to expand:

- Works
- Archive
- MiuMiu
- Lab


Do not make the homepage dependent only on 3D Photo.


The homepage represents Achilles Cat.
